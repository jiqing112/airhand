# 界面规范

控制台界面的设计变量（**Design Token**）和组件语义。改样式从这里下手，组件只用 token、不写裸值。

## 文件

| 文件 | 内容 |
|---|---|
| `client/src/styles/tokens.css` | 全部设计变量：色彩、圆角、间距、字号、焦点环、动效时长 |
| `client/src/styles/base.css` | Reset 和元素基础、通用工具类（`.muted`、`.mono`……） |
| `client/src/styles.css` | 组件层（标签栏、卡片、弹出层、会话……），按页面分节 |
| `client/src/components/ui/` | 原语组件：`Tooltip`（延迟浮出、贴边翻转）。Popover、ConfirmDialog 在 `components/` 里 |

## Token

### 圆角（五档 + 圆）

件越小、圆角越小：

| Token | 值 | 用在 |
|---|---|---|
| `--r-xs` | 4px | 徽标、小标签 |
| `--r-s` | 6px | 输入框、小按钮 |
| `--r-m` | 8px | 按钮、菜单项、Tooltip |
| `--r-l` | 12px | 卡片、弹出层、目标输入框 |
| `--r-xl` | 16px | 对话框、大面板 |
| `--r-full` | 999px | 头像、圆点、胶囊 |

大面（卡片、对话框、弹出层）在支持的浏览器上自动启用连续圆角（`corner-shape: squircle`，`@supports` 渐进增强，不支持的用普通圆角）。

### 间距（4 的倍数）

`--sp-1`(4px) 到 `--sp-12`(48px)。按嵌套关系分配：

- 同层元素之间：相邻两档里小的那档（例如列表项之间 `--sp-2`）
- 容器内缩：上下左右用同一档（例如卡片 `--sp-5`，里面的分组再缩 `--sp-3`）
- 分组之间：比组内大一到两档（例如组内 `--sp-2`、组间 `--sp-4`）

### 字号

`--fs-s`(12px) 辅助、`--fs-m`(14px) 正文、`--fs-l`(16px) 区块标题、`--fs-xl`(20px) 大标题。行高 `--lh-tight`(1.3) 用于标题、`--lh-normal`(1.5) 用于正文。

## Do / Don't

### 组件语义

| 场景 | 用 | 不要用 |
|---|---|---|
| 主操作（连接、确认） | `.primary-btn`，一屏一个 | 一屏多个主按钮 |
| 破坏性操作（断开、遗忘） | `.danger-btn`，放在确认对话框里 | 直接放在列表项上生效 |
| 低频说明（限制、后果） | `title` / `Tooltip` 折叠 | 常驻的说明文字 |
| 选择互斥的一项 | `.segmented`（预设、语言） | 下拉菜单（多一次点击） |
| 开关一项设置 | `.switch` | 复选框样式 |

### 文案

- **布局自解释优先**：一个输入框配占位符（"控制码或 IP 地址"）胜过标签 + 输入框
- 砍掉营销和口语化说明；保留下来的说明按使用频率折叠进 tooltip / `title`
- 错误提示说**用户该做什么**，技术细节（`detail`）原样附在后面
- 数字用等宽字体（`.mono` / `font-variant-numeric: tabular-nums`）：控制码、地址、延迟

### 已有的范例

- 连接页（`ConnectView.tsx`）：单智能输入（6 位数字 = 控制码，其余 = `IP:端口`）、按需出现的配对码、无标签行
- 服务器面板（`AppMenu.tsx` 的 `ServerPanel`）：键值对 + 状态徽章，不解释概念
